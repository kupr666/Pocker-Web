# Archive

Статус: проект документации API v0.1. Схемы и реализация пока не созданы.

## Ответственность

Долговременное хранение завершённых и отменённых раздач и выдача истории
их участникам. Текущую игру не обслуживает. В MVP автоматического удаления нет.

Данные поступают из Game через 24 часа после finished_at/cancelled_at.
Запись: hand_id, table_id, время, исходные/итоговые стеки, участники,
правила на момент игры, карты и признак раскрытия, действия, банки,
распределения выигрыша, статус завершения/отмены, версия формата.

## API

Ниже — предлагаемый API и модель истории. Protobuf-контракты пока не оформлены.

| Метод | Доступ |
| --- | --- |
| StoreHand | Только доверенный процесс переноса Game |
| ListHands | Только история запрашивающего пользователя |
| GetHand | Только участник раздачи |

Archive не возвращает сырую внутреннюю запись через пользовательские методы.
Приватные карты фильтруются при каждом чтении; владелец и зритель не получают
дополнительных прав. Закрытие стола не влияет на права бывшего участника.

## Надёжный перенос

1. Game выбирает окончательно зафиксированную раздачу старше 24 часов.
2. Вызывает StoreHand с постоянным hand_id и неизменяемым содержимым.
3. Archive проверяет схему и надёжно сохраняет запись.
4. Повтор той же записи возвращает успех; другое содержимое с тем же hand_id — конфликт.
5. Только после ack Game может удалить свою копию.

Если ack потерян, запись отправляется повторно. Недоступность Archive задерживает
перенос, а не игру. Во время хранения двух копий Gateway устраняет дубликаты.
Выбор источника по возрасту некорректен: старые записи могут ещё быть в Game.

## Пагинация

Одинаковый порядок с Game: finished_at DESC, hand_id DESC.
Поддерживается граница ключа и верхняя граница среза. Запрос всегда ограничен
участником; пользователь не выбирается произвольным полем HTTP.

## Проверки

Потерянный ack, повтор StoreHand, конфликт содержимого, перенос во время
пагинации, доступ после закрытия стола, запрет зрителю и фильтрация карт.
