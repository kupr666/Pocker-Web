# Wallet — после MVP

Статус: отложен. Публичные маршруты, protobuf и реализация пока не создаются.

## Согласованные этапы

1. MVP: только фишки внутри стола, которыми управляет Game.
2. Бесплатная валюта аккаунта: начальное начисление при регистрации,
   вход за стол со своего баланса, возврат остатка. Для этого создаётся Wallet.
3. Отдельная покупаемая валюта и интеграция с платежами.

## Предлагаемая ответственность

Балансы по валютам, журнал операций, идемпотентные начисления,
резервирование/внесение за стол, возврат средств. Wallet не считает банки
и не обрабатывает каждую ставку: это делает Game.

Платёжный сервис/провайдер подтверждает оплату, Wallet выполняет начисление.
Вызов начисления от недоверенного клиента недопустим.

## До проектирования контрактов

Нужно согласовать размер начального начисления, пополнения бесплатной валюты,
назначение покупаемой валюты, перевод между игроками, обмен и возможность
вывода. Эти возможности пока не утверждены и не подразумеваются автоматически.
