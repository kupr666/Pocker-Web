## Источники истины

- Продуктовое поведение — `product.md`.
- Обязанности и сценарии — документы сервисов и `flows.md`.
- HTTP-маршруты — [обзор API](api/overview.md); OpenAPI пока не создан.
- WebSocket — [описание протокола](services/gateway/websocket.md); JSON Schema пока не создана.
- Внутренние методы и данные — документы сервисов; новые `.proto` пока не создаются.
- Неутверждённые значения и механизмы — `decisions/open-questions.md`.

Изменение поведения должно сопровождаться изменением требований и контрактов
в одном PR. После реализации важные принятые технические решения оформляются
отдельными ADR; предложения нельзя молча переводить в согласованные требования.
